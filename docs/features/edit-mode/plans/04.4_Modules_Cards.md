## Implementierung

### Schritt 1: Shared Card-Komponente erweitern

Die `Card`-Komponente ist intern und wird nur von CardRow + CardGrid verwendet. Sie bekommt ein optionales `propPathPrefix`-Prop (z.B. `'cards[0]'`), das die Hooks brauchen um den korrekten Pfad zu bauen.

**Datei:** `src/elements/shared/Card.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../builder/useEditableText';
import { useEditableImage } from '../../builder/useEditableImage';
```

`propPathPrefix` als optionales Prop hinzufügen (nur intern, nicht im Zod-Schema):
```tsx
// Alt:
interface CardProps {
  imageSrc?: string;
  imageAlt?: string;
  title: string;
  body?: string;
}

// Neu (internes React-Prop, kein Schema-Change):
interface CardProps {
  imageSrc?: string;
  imageAlt?: string;
  title: string;
  body?: string;
  propPathPrefix?: string; // z.B. 'cards[0]' — nur für Edit Mode
}
```

In der Komponente Hooks aufrufen:
```tsx
export function Card({ imageSrc, imageAlt, title, body, propPathPrefix = 'cards[0]' }: CardProps) {
  const titleEdit = useEditableText(`${propPathPrefix}.title`);
  const bodyEdit = useEditableText(`${propPathPrefix}.body`);
  const { overlayElement } = useEditableImage(imageSrc ?? '', `${propPathPrefix}.imageSrc`);
  // ...
}
```

JSX anpassen:
```tsx
// Alt:
{imageSrc && <img src={imageSrc} alt={imageAlt} className="card__img" />}
<h3 className="card__title">{title}</h3>
{body && <p className="card__body">{body}</p>}

// Neu:
{imageSrc && (
  <div className="card__img-wrap">
    <img src={imageSrc} alt={imageAlt} className="card__img" />
    {overlayElement}
  </div>
)}
<h3 className="card__title" {...titleEdit}>{title}</h3>
{body && <p className="card__body" {...bodyEdit}>{body}</p>}
```

**Datei:** `src/elements/shared/Card.css`

Wrapper-Klasse hinzufügen:
```css
.card__img-wrap {
  position: relative;
  line-height: 0;
}
```

### Schritt 2: CardRow + CardGrid — propPathPrefix weitergeben

Da beide Module bereits Card verwenden, müssen sie nur den korrekten Index-Pfad übergeben.

**Datei:** `src/elements/content/CardRow/CardRow.tsx`

```tsx
// Alt:
{cards.map((card, i) => (
  <Card key={i} {...card} />
))}

// Neu:
{cards.map((card, i) => (
  <Card key={i} {...card} propPathPrefix={`cards[${i}]`} />
))}
```

**Datei:** `src/elements/content/CardGrid/CardGrid.tsx`

Identische Änderung:
```tsx
// Alt:
{cards.map((card, i) => (
  <Card key={i} {...card} />
))}

// Neu:
{cards.map((card, i) => (
  <Card key={i} {...card} propPathPrefix={`cards[${i}]`} />
))}
```

**Erklärung:** Da `Card` den `propPathPrefix` erhält und intern die Hooks aufruft, funktioniert es für beide Module identisch. Keine Duplizierung.
