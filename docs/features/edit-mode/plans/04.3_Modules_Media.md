## Implementierung

### Schritt 1: ImageBlock

**Datei:** `src/elements/media/ImageBlock/ImageBlock.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
import { useEditableImage } from '../../../builder/useEditableImage';
```

In der Komponente:
```tsx
const { overlayElement } = useEditableImage(src, 'src');
const captionEdit = useEditableText('caption');
```

JSX anpassen — Bild braucht einen `position: relative`-Wrapper:
```tsx
// Alt:
<figure className="imageblock">
  <img src={src} alt={alt} className="imageblock__img" style={{ objectFit, maxHeight }} />
  {caption && <figcaption className="imageblock__caption">{caption}</figcaption>}
</figure>

// Neu:
<figure className="imageblock">
  <div className="imageblock__img-wrap">
    <img src={src} alt={alt} className="imageblock__img" style={{ objectFit, maxHeight }} />
    {overlayElement}
  </div>
  {caption && <figcaption className="imageblock__caption" {...captionEdit}>{caption}</figcaption>}
</figure>
```

**Datei:** `src/elements/media/ImageBlock/ImageBlock.css`

Wrapper-Klasse hinzufügen:
```css
.imageblock__img-wrap {
  position: relative;
  display: block;
  line-height: 0; /* Verhindert Whitespace unter img */
}
```

### Schritt 2: Gallery

Gallery rendert mehrere Bilder in einem `.map()`. Extraktion als interne Komponente ist nötig (Hook-Regel).

**Datei:** `src/elements/media/Gallery/Gallery.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
import { useEditableImage } from '../../../builder/useEditableImage';
```

Interne Komponente am Ende der Datei:
```tsx
function GalleryItem({
  image,
  index,
}: {
  image: { src: string; alt: string; caption?: string };
  index: number;
}) {
  const { overlayElement } = useEditableImage(image.src, `images[${index}].src`);
  const captionEdit = useEditableText(`images[${index}].caption`);
  return (
    <figure className="gallery__item">
      <div className="gallery__img-wrap">
        <img src={image.src} alt={image.alt} className="gallery__img" />
        {overlayElement}
      </div>
      {image.caption && (
        <figcaption className="gallery__caption" {...captionEdit}>
          {image.caption}
        </figcaption>
      )}
    </figure>
  );
}
```

In der `Gallery`-Komponente, den Map-Aufruf ersetzen:
```tsx
// Alt:
{images.map((img, i) => (
  <figure key={i} className="gallery__item">
    <img src={img.src} alt={img.alt} className="gallery__img" />
    {img.caption && <figcaption …>{img.caption}</figcaption>}
  </figure>
))}

// Neu:
{images.map((img, i) => (
  <GalleryItem key={i} image={img} index={i} />
))}
```

**Datei:** `src/elements/media/Gallery/Gallery.css`

Wrapper-Klasse hinzufügen:
```css
.gallery__img-wrap {
  position: relative;
  line-height: 0;
}
```

### Schritt 3: MediaText

**Datei:** `src/elements/content/MediaText/MediaText.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
import { useEditableImage } from '../../../builder/useEditableImage';
```

In der Komponente:
```tsx
const { overlayElement } = useEditableImage(imageSrc, 'imageSrc');
const headingEdit = useEditableText('heading');
const bodyEdit = useEditableText('body');
```

JSX anpassen — Bild-Seite braucht Wrapper:
```tsx
// Alt:
<div className="mediatext__image">
  <img src={imageSrc} alt={imageAlt} className="mediatext__img" />
</div>

// Neu:
<div className="mediatext__image">
  <div className="mediatext__img-wrap">
    <img src={imageSrc} alt={imageAlt} className="mediatext__img" />
    {overlayElement}
  </div>
</div>
```

Text-Seite:
```tsx
// Alt:
{heading && <h3 className="mediatext__heading">{heading}</h3>}
<p className="mediatext__body">{body}</p>

// Neu:
{heading && <h3 className="mediatext__heading" {...headingEdit}>{heading}</h3>}
<p className="mediatext__body" {...bodyEdit}>{body}</p>
```

**Datei:** `src/elements/content/MediaText/MediaText.css`

Wrapper-Klasse hinzufügen:
```css
.mediatext__img-wrap {
  position: relative;
  line-height: 0;
}
```
