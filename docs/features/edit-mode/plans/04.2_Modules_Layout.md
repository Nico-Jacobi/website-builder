## Implementierung

### Schritt 1: Header

**Datei:** `src/elements/layout/Header/Header.tsx`

Imports hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
import { useEditableImage } from '../../../builder/useEditableImage';
```

In der Komponente:
```tsx
const titleEdit = useEditableText('title');
const subtitleEdit = useEditableText('subtitle');
const { overlayElement: iconOverlay } = useEditableImage(icon ?? '', 'icon');
```

JSX anpassen (Texte):
```tsx
// Alt:
<span className="header__title">{title}</span>
{subtitle && <span className="header__subtitle">{subtitle}</span>}

// Neu:
<span className="header__title" {...titleEdit}>{title}</span>
{subtitle && <span className="header__subtitle" {...subtitleEdit}>{subtitle}</span>}
```

JSX anpassen (Icon — braucht Wrapper mit `position: relative`):
```tsx
// Alt:
{icon && <img src={icon} alt="" className="header__icon" />}

// Neu:
{icon && (
  <div className="header__icon-wrap">
    <img src={icon} alt="" className="header__icon" />
    {iconOverlay}
  </div>
)}
```

**Datei:** `src/elements/layout/Header/Header.css`

Klasse hinzufügen (am Ende der Datei):
```css
.header__icon-wrap {
  position: relative;
  display: inline-flex;
}
```

**Hinweis zu Links:** `links[].label` wird in Header als Navigationslinktext gerendert. Da Navigation-Links üblicherweise nicht inline editiert werden (Href ist genauso wichtig wie Label), werden Nav-Link-Texte in diesem Feature **nicht** editierbar gemacht. Das würde eine komplexere UI brauchen (Href + Label zusammen). Das ist explizit Out of Scope.

### Schritt 3: Footer

Footer hat zusätzlich Spalten-Headings die editierbar sein sollen.

**Datei:** `src/elements/layout/Footer/Footer.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
```

Da Footer Spalten in einem `.map()` rendert, werden die Column-Headings als eigene Komponente extrahiert (Hook-Regel: kein Aufruf in Loops):

```tsx
// Neue interne Komponente am Ende der Datei:
function FooterColumn({
  col,
  colIndex,
}: {
  col: { heading?: string; links: { label: string; href: string }[] };
  colIndex: number;
}) {
  const headingEdit = useEditableText(`columns[${colIndex}].heading`);
  return (
    <div className="footer__column">
      {col.heading && (
        <h4 className="footer__column-heading" {...headingEdit}>
          {col.heading}
        </h4>
      )}
      <ul className="footer__column-links">
        {col.links.map((link, j) => (
          <li key={j}>
            <a href={link.href} className="footer__link">{link.label}</a>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

In der `Footer`-Komponente Hooks für tagline + copyright, und map durch `FooterColumn` ersetzen:
```tsx
const taglineEdit = useEditableText('tagline');
const copyrightEdit = useEditableText('copyright');

// Alt:
{columns?.map((col, i) => (
  <div key={i} className="footer__column">
    {col.heading && <h4 …>{col.heading}</h4>}
    …
  </div>
))}

// Neu:
{columns?.map((col, i) => (
  <FooterColumn key={i} col={col} colIndex={i} />
))}
```

Tagline + Copyright:
```tsx
// Alt:
{tagline && <p className="footer__tagline">{tagline}</p>}
{copyright && <small className="footer__copyright">{copyright}</small>}

// Neu:
{tagline && <p className="footer__tagline" {...taglineEdit}>{tagline}</p>}
{copyright && <small className="footer__copyright" {...copyrightEdit}>{copyright}</small>}
```
