## Implementierung

### Schritt 1: HeroBanner

**Datei:** `src/elements/layout/HeroBanner/HeroBanner.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
```

In der Komponente (vor dem return):
```tsx
const headingEdit = useEditableText('heading');
const subheadingEdit = useEditableText('subheading');
const ctaLabelEdit = useEditableText('ctaLabel');
```

JSX-Elemente anpassen:
```tsx
// Alt:
<h1 className="herobanner__heading">{heading}</h1>
{subheading && <p className="herobanner__subheading">{subheading}</p>}
{ctaLabel && <a href={ctaHref} className="herobanner__cta">{ctaLabel}</a>}

// Neu:
<h1 className="herobanner__heading" {...headingEdit}>{heading}</h1>
{subheading && <p className="herobanner__subheading" {...subheadingEdit}>{subheading}</p>}
{ctaLabel && <a href={ctaHref} className="herobanner__cta" {...ctaLabelEdit}>{ctaLabel}</a>}
```

**Hinweis:** `{...editProps}` streut `contentEditable`, `suppressContentEditableWarning`, `className`, `onBlur` auf das Element — wenn Edit Mode aus ist, ist `editProps` ein leeres Objekt `{}`.

### Schritt 4: StatRow

StatRow rendert eine Liste von `{value, label}` Paaren. Jeder Eintrag braucht einen index-bewussten Pfad.

**Datei:** `src/elements/content/StatRow/StatRow.tsx`

Import hinzufügen:
```tsx
import { useEditableText } from '../../../builder/useEditableText';
```

Da Hooks nicht in Loops aufgerufen werden dürfen, wird jedes Stat-Tile als eigene Komponente extrahiert:

```tsx
// Neue interne Komponente am Ende der Datei (nicht exportieren):
function StatTile({ stat, index }: { stat: { value: string; label: string }; index: number }) {
  const valueEdit = useEditableText(`stats[${index}].value`);
  const labelEdit = useEditableText(`stats[${index}].label`);
  return (
    <div className="statrow__tile">
      <span className="statrow__value" {...valueEdit}>{stat.value}</span>
      <span className="statrow__label" {...labelEdit}>{stat.label}</span>
    </div>
  );
}
```

In der `StatRow`-Komponente, den bisherigen `.map` ersetzen:
```tsx
// Alt:
{stats.map((stat, i) => (
  <div key={i} className="statrow__tile">
    <span className="statrow__value">{stat.value}</span>
    <span className="statrow__label">{stat.label}</span>
  </div>
))}

// Neu:
{stats.map((stat, i) => (
  <StatTile key={i} stat={stat} index={i} />
))}
```

**Erklärung:** React-Hooks müssen auf Top-Level einer Komponente aufgerufen werden (nicht in Loops). Durch Extraktion in `StatTile` werden die Hooks regelkonform pro Item aufgerufen.
